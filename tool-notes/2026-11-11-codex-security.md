# 工具笔记：Codex Security（OpenAI 官方）——找、查、修一条龙的安全扫描工具

- **日期**：2026-11-11
- **链接**：https://github.com/openai/codex-security
- **来源**：OpenAI 官方仓库／@githubtrending 频道帖转引

## 一句话结论

Codex Security 是 OpenAI 官方出的代码安全工具，提供 CLI 与 TypeScript SDK：扫全仓、单个文件或 Git 变更，定位漏洞后给补丁、验证修复是否成立，结果还能导出到 Jira、Linear、GitHub，也可以挂成 GitHub Action 自动跑。

## 它做什么

- 扫描对象灵活：整个仓库、指定文件、或一次提交的 diff，适合塞进日常提交流程而不是攒到大审计。
- 不止报告问题：给出补丁并验证修复，把「发现漏洞」和「修掉漏洞」接成一条链。
- 两种用法：本地 CLI 手动跑，或 GitHub Action 在流水线里自动跑。

## 为什么值得收

- 直接对口网络安全学习线（WGU 在读方向）：这是大厂官方把「AI 做安全审计」产品化的样本，从它的扫描范围、补丁生成与验证方式，能反推出现在行业里安全自动化的实际水位。
- 对日常代码工作也实用：自有仓库多，提交前用它扫一遍 diff，成本低、能拦下低级漏洞。

## 证据与可信度

- 一手来源为 OpenAI 官方仓库；功能描述以仓库 README 为准，本条只做转述与定位，未实测安装。
