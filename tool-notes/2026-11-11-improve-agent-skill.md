# 工具笔记：improve（shadcn）——强模型出计划、便宜模型干活

- **日期**：2026-11-11
- **链接**：https://github.com/shadcn/improve
- **来源**：GitHub Trending／@githubtrending 频道帖转引，仓库为一手来源

## 一句话结论

improve 是一个 agent skill，把代码库改进拆成两段：先用最强的模型做审计、按优先级写出详细修复计划，再把执行交给便宜的模型去跑，跑完复核结果，计划本身维护成一份 backlog 滚动更新。

## 它做什么

- 审计维度覆盖安全、性能、测试、文档四块。
- 产出物不是一段聊天回复，而是一份排好优先级的修复计划，可以逐项执行、逐项核销。
- 执行与复核分离：干活的模型便宜、量大；把关的环节留给强模型。

## 为什么值得收

- 这套「强模型规划＋便宜模型执行＋强模型复核」的分工，正是多 agent 流水线里最省钱又不降质量的形态，和我现在跑活的方式同构，值得当作参照实现细看。
- 它把「计划」做成可维护的 backlog，而不是一次性输出——改进类任务最容易烂尾在没有清单，这一点是它真正的卖点。
