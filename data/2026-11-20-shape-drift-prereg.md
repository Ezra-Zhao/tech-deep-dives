# 预注册：形状相关面积漂移机制隔离实测（2026-11-20，跑主实验前冻结）

承接 2026-11-08 篇第 3.4 节未隔离机制与局限二/三：方块杂物归一化轮廓放大后中位 +24%/最大 +26.6%（对名义），圆 +20%/+9.5%；当时只给「插值晕染＋闭运算填角」的相容解释，未分份额；多边形（三角/多角碎片）的有效轮廓带是否比方块更宽亦未测。本轮用单形状隔离台架把两因子正交拆开，并量多边形的带宽。

## 先验（只许已发表数据）
- 2026-11-08 事后隔离（在植入现场、同管线 close7→open7、INTER_LINEAR 放大）：r=6 方（边 11、名义 121）归一化轮廓中位 s=1 为 109.0，s=1.5–3.0 为 128.3/129.2/136.9/135.0，最大 153.2@s=2；r=6 圆（名义 113.1）中位 s=1 为 90.0、高 s 档中位约 108、最大 123.8。
- 2026-10-30/11-08：开运算先削——s=1 轮廓普遍比名义小（圆 −20%、方 −10% 量级）。
- 结构事实：NEAREST 放大不产生新像素值，掩膜二值性保持、无灰度晕染；CUBIC 有过冲（ringing），可产生带外像素值。

## 实验设计（冻结）
- 台架：240×240 画布，背景纯色 BGR(40,120,40)（经断言不进花瓣掩膜），形状用杂物粉 BGR(147,20,255) 单独居中绘制，与 2026-11-08 植入同色。
- 形状（名义面积约 121）：圆 r=6（113.1）、方边 11（121）、等边三角边 17（125.2）、正五边形外接半径 10（118.9）、正六边形外接半径 7（127.3）、菱形（45° 方）对角线 16（128.0）；尺寸对照：圆 r=12（452.4）、方边 21（441）。
- 复本：每形状 16 个（整数中心位置抖动 ±6 像素、多边形旋转角 0°–75° 步进 5°、圆/方用位置抖动），逐个单独成像。
- 管线：与检测器逐字同法——BGR→HSV→_petal_mask（直接 import Bloom-Counter 的 ColorSegmentationDetector._petal_mask）→形态学臂→findContours(RETR_EXTERNAL)→contourArea，取含中心的轮廓。
- 因子：插值 ∈ {INTER_LINEAR, INTER_CUBIC, INTER_NEAREST}（放大到 240s×240s）；形态学臂 ∈ {full（close7→open7，与检测器同序同核）, close_only, open_only, none}；s ∈ {1.0, 1.5, 2.0, 2.5, 3.0}（s=1 时插值臂退化、只跑形态学臂）。
- 读数：归一化面积 = contourArea / s²；漂移率 = 归一化面积/名义面积 − 1；有效带宽 = (max − median)/名义面积（同形状同臂同 s、16 复本）。
- 份额分解（在 s∈{2.0, 2.5, 3.0} 合池中位上做）：以 s=1 同臂读数为基线，放大增量 Δ(臂,插值) = median_norm(s) − median_norm(1)。插值份额 = Δ(none, LINEAR) − Δ(none, NEAREST)；闭运算份额 = Δ(close_only, NEAREST) − Δ(none, NEAREST)；开运算份额 = Δ(open_only, NEAREST) − Δ(none, NEAREST)；总增量 = Δ(full, LINEAR)；交互残差 = 总增量 − 三份额之和 − Δ(none, NEAREST)。逐形状报告，不强行凑 100%。

## 预注册预测（跑数前写死，错了照实报）
- P1（复刻锚）：full+LINEAR 下方块中位漂移在 s=2.0 与 3.0 分别落在 +3%～+16% 与 +5%～+18%（对名义；由先验 129.2/121−1=+6.8%、135.0/121−1=+11.6% 给带，容差含台架差异——本轮背景为纯色、形状单独成像，与在场植入的邻域条件不同）；圆中位漂移两档均低于方块。
- P2（插值份额为正且可观）：方块在 none 臂下 LINEAR 的放大增量比 NEAREST 高至少 3 个百分点（对名义，下同）；圆的同差小于方块。
- P3（闭运算填角份额大于开运算）：方块 close_only(NEAREST) 增量为正且大于 open_only(NEAREST) 增量至少 2 个百分点；三角同向。
- P4（多边形带宽）：full+LINEAR、s≥2 合池的有效带宽（max−median）排序中，三角 ≥ 方块 > 圆；六边形带宽最接近圆。
- P5（CUBIC 过冲）：方块 none 臂 CUBIC 增量 ≥ LINEAR 增量（过冲不小于双线性晕染的面积效应）；若 CUBIC 反而更小，照实报并改解释。
- P6（尺寸对照）：r=12 圆与边 21 方的 full+LINEAR 中位漂移（对名义）均小于小尺寸同形状——漂移是周长/面积比驱动的边界效应，大形状相对漂移更小。
