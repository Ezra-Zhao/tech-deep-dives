## 量法（跑分前定义，全部只用 exporter 已发布量加服务器计数）

- L：端到端总丢包（nal_loss_ratio，部署口径）；L_iso：以代理 in_client
  为分母的隔离口径丢包（与 2026-10-28 篇同定义）。
- OLD：L 大于 0.75（部署）与 L_iso 大于 0.75（隔离）两口径分开报。
- F_c = forwarded - echoed（2026-11-01 篇重构式，逐轮验恒等式）。
- D = 1 - in_server / F_c（整段丢弃率，2026-11-01 篇 CAND 用量，
  CAND 判定线沿用冻结的 D 大于 0.10）。
- 段内拆分（本轮新增，服务器计数来自 exporter 的
  nal_server_packets_total 与原始 server_stats，两处对账）：
  D_srv = 1 - server_received / F_c（去程子段：代理放行到服务器收包）；
  D_ret = 1 - in_server / server_echoed（回程子段：服务器回显到代理收包）。
  代数上 (1-D) = (1-D_srv) x (1-D_ret)，三量不是独立的。
- 前向基线（2026-10-28 的 28 轮存档，本轮跑分前已复算）：
  D_srv 与 D 逐轮相等、D_ret 逐轮恰为 0.0000（28/28），
  即前向轮的整段丢弃全部落在去程子段。

## 预注册预测（跑分前写死，错了在正文公开认）

P1 锚点：q=0 四轮 L 均值落在前向 q=0 均值 0.5315 的正负 0.02 内，
    且四轮 D 全部不大于 0.03。
P2 等价（OLD）：隔离口径触发形态与前向相同——q=0.40 时 0/4、
    q=0.50 与 0.60 时 4/4；即 0.75 规则的检出临界 q* 约 0.47 不因
    丢弃方向移动（部署口径若有台架缺口顶线的提前触发，逐轮用
    分解账归因、不算 P2 破例）。
P3 等价（D）：D 读出回程真值——以垫片回程实测丢弃率
    dropped_extra / in_server_shim 为真值，28 轮 |D - 真值| 中位数
    不大于 0.02；CAND 在 q 不小于 0.20 各档 4/4、q=0 档 0/4，
    q=0.10 为临界档不预言方向。
P4 形态翻转：本轮 D_srv 四轮均值每档不大于 0.03（去程子段干净），
    D_ret 与名义 q 的误差中位数（全网格）不大于 0.02；
    与前向基线正好镜像（前向 D_srv 约等于 q、D_ret 等于 0）。
P5 服务器白工：server_echoed 本轮约等于 F_c（每档均值与 F_c 均值
    之差不大于 3%），而前向同档 server_echoed 约等于 F_c x (1-q)；
    两方向在 q=0.60 档的 server_echoed 均值差不小于 F_c 均值的 40%。
