# 预注册：杂物尺寸扫描实测（2026-11-18，跑主数前冻结）

承接 2026-11-07 篇局限原文（第一外推边界）：「杂物只有一种尺寸（r=12）……
更大的杂物（附加超过花苞与门槛的最大距离约 557）会把全部花苞推过线，
P3 的 50% 猜想在那个尺寸上反而成立——尺寸维度未扫，是本篇结论外推的
第一边界。」本轮兑现：杂物半径从小到大扫，量改判带宽与全数改判的转折
点，并验 2026-11-07 第 3.3 节的分布口径改判公式。选题池待写第 14 条
（待写区第 1–4 条仍素材不足暂缓、第 8 条待 Ezra 确认关闭）。

注：2026-11-07 局限里「最大距离约 557」指最大花苞（单独面积 499.5）到
门槛的距离（900−499.5≈400）之外的另一口径混写，本篇以实测分布为准：
全场花苞单独面积 242.0–499.5（2026-11-07 posthoc），全数改判要求附加
面积 ≥ 900 − 最小花苞单独面积 ≈ 658；最大花苞先行改判只要求附加
≥ 900 − 499.5 ≈ 400（r=12 浅触附加 437 已达、与实测 14.3% 峰值相容，
但当时改判的 8 个全是单独面积 ≥457 的最大一截——附加的口径差在此）。

## 实验设计（冻结）

- 基底与宿主：与 2026-11-07 逐字同法——模拟器 4 场景（种子
  101/202/303/404，210 真值），宿主选择函数（RC=12 口径、16 方向取最
  空、开花/花苞交错至多 28/场）原样复用，宿主集与 2026-11-07 相同
  （112 个，开花/花苞各 56）。宿主单独轮廓面积同轮在干净图上实测。
- 杂物：同色实心圆（粉/白/黄轮转，同 2026-11-07），半径
  rc ∈ {4, 6, 8, 10, 12, 15, 18, 21, 24} 九档；每宿主 1 块，后画覆盖。
- 间距 gap（边到边有符号距离，名义）：{-18, -8, -3, 0, 2, 4, 8}，
  中心距 d = r_宿主 + rc + gap；rc 小且 gap 深时 d 可为负，钳制到 0
  并逐条记录实际 d 与实际 gap。gap=8 为合并归零对照档。
- 主臂 only：检测器默认参数（min_area=120、bloom_area_min=900、核 7，
  CLOSE 后 OPEN）。宿主结局走轮廓法（同 2026-11-07：merged / correct /
  migrated / lost），端到端另跑真检测器记全场 TP/FP/FN。
- 逐条记录：宿主标签、单独面积、merged、结局、合并轮廓面积、附加面积
  （合并面积 − 单独面积）、杂物中心到最近非宿主真值的边到边净距
  nbr_clear（负值=杂物盘压到邻居，事后敏感性分析剔除重算）。
- 杂物单独参照：每档 rc 在纯叶面背景（种子 7001–7004）中心画盘，过
  同管线记含中心轮廓面积与 ≥120 轮廓数（A_alone(rc)）。
- 分布公式验证（事后脚本，口径在此冻结）：每 (rc, gap) 格取全体合并
  宿主（开花+花苞）的附加面积中位数 A_eff；预测改判数 = 合并花苞宿主
  中单独面积 ≥ 900 − A_eff 的个数。逐格比 |预测 − 实测|，并合池统计。

## 预注册预测（跑后逐条对账，错了照实报）

- P1（单独可见性）：A_alone(rc) 随 rc 单调不减；rc=4/6 单独轮廓
  <120（开运算蚀刻后不存活或低于地板，单独放置零检出），rc=8 起
  ≥120 存活；rc=12 复刻 406±10%。
- P2（分布公式）：逐格 |预测改判数 − 实测改判数| ≤2 的格占比 ≥80%
  （合并花苞数 ≥5 的格计入）；合池预测总数与实测总数相对偏差 ≤15%。
- P3（全数改判转折）：gap=−3 档，花苞合并宿主的改判率随 rc 单调不
  降（容一档噪声），rc=15 时 ≥70%、rc=18 时达 100%（全数改判转折
  rc* ∈ {15, 18}，对应 A_eff 越过 ≈658）；rc=12 复刻 ≈14%（同口径
  2026-11-07 为 14.3%）。
- P4（改判带宽向深端扩张）：改判出现的 gap 集合：rc≤12 时只在
  {-3, 0, 2, 4}；rc≥18 时扩张到 −8 与 −18（深压不再无害）；所有 rc
  在 gap=8 改判恒 0、merged 率 ≤5%（合并上沿由核定、不随 rc 动）。
- P5（开花侧与丢失）：开花宿主 correct 全格 100%（附加只涨面积、
  不改 bloom 标签）；lost 全格 0（同色附加不删宿主）。
- P6（端到端 FP 对账）：每格 FP ≈ 改判数 + 未合并且单独存活
  （A_alone≥120）的杂物数，逐格差 ≤3 的格占比 ≥80%；且 rc≥18 的
  未合并杂物 FP 以 bloom 类为主（A_alone≥900），rc≤15 以 bud 类为主。

## 判定口径

- 主结论量：改判率（分 rc、分 gap、限花苞合并宿主）、A_alone 与
  A_eff 曲线、全数改判转折 rc*、分布公式逐格误差、FP 对账、
  nbr_clear<0 剔除后的敏感性复算。
- 数字以 bench JSON 为准；终校脚本化核对文中数字与 JSON。
