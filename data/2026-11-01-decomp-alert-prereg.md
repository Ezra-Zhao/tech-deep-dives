# 分解感知告警验证 · 预注册（2026-11-01，跑分前冻结）

承接 2026-10-28 篇第 4 节方向与第 5 节未解问题：实现「由代理逐级计数推算期望
端到端丢包、与实测端到端丢包作差」的候选规则，与现行 0.75 总丢包规则同场对照。

## 候选规则的定义（只许用 exporter 已发布量）

exporter（src/prom_exporter.py 的 collect()）发布的量里，与本规则有关的只有：
sent（nal_packets_sent_total{fault_sustained}）、echoed（nal_packets_echoed_total）、
in_client / in_server / forwarded（nal_fault_proxy_packets_total 的 kind 标签；
注意 dropped_loss/dropped_flap/forwarded 都是双向合计、不分方向）。

由这五个数重构方向量（恒等式，不引入新测量）：
- 代理回程放行数 F_s = echoed（依据：代理 s2c forward 计数与发生器 echoed
  在 2026-10-28 的 28 轮里逐轮全等；本轮在存档重评与新活体两层都复核此恒等式，
  不成立的轮次单独报告、不进主结论）。
- 代理去程放行数 F_c = forwarded − echoed（forwarded 是双向合计，减去回程即去程）。
- 回程腿存活率 b = echoed / in_server。
- 期望回声数 E_exp = F_c × b（若去程放行包全部到达服务器并被回显，
  只有回程腿再丢，发生器应收到的回声数）。
- 期望丢包 L_exp = 1 − E_exp / sent；实测丢包 L = 1 − echoed / sent。
- 段丢弃率 D = 1 − in_server / F_c（去程放行之后、回程进入代理之前这一段
  ——垫片＋服务器＋其间回环跳——的丢弃率；代数上 D 与 (L − L_exp) 只差一个
  尺度因子：L − L_exp = (E_exp − echoed)/sent = D × E_exp/sent）。

## 冻结的判定线（跑分前定死，事后不许挪）

- 候选规则 CAND：D > 0.10 报警。选 0.10 的理由（跑分前写明）：它须高于段内
  正常跳间缺口的量级（2026-10-28 全网格仅见一轮代理→垫片缺口 145 个，
  约占该轮 F_c 的 2.7%），又须远低于现行规则的检出临界 q*≈0.47；
  0.10 另留一档敏感性口径 D > 0.05 只报告、不作主判定。
- 现行规则 OLD：L > 0.75（与 2026-10-28 篇同口径，隔离口径另报）。
- 估计准确性口径：|D − q_真值|（活体层 q 为垫片名义值，另以垫片实测
  丢弃率 dropped_extra/in_client 作第二真值对账）。

## 三层证据（顺序固定）

A. 存档重评：2026-10-28 的 28 轮活体全账（q 网格 0–0.60 × 4），只用上面
   五个 exporter 量重算 OLD 与 CAND，逐轮与真值 q、台架缺口
   （1 − in_client/sent）对照。这一层是旧数据新规则，文中必须如实标注。
B. 新活体验证（留出）：同组件同垫片、新种子（extra_seed 基数 31000），
   q ∈ {0, 0.15, 0.30} × 4 次重复共 12 轮；0.15 与 0.30 两档在 OLD 的
   盲区内（< 0.47）、在 CAND 的线之上（> 0.10），是两条规则预言相反的档位。
   判定线不动，跑完才揭晓触发账。
C. 合成扰动：拿 A 层 q=0 与 q=0.20 的轮次计数，人工注入台架缺口
   g ∈ {0.1, 0.2, 0.3}（按比例削减 in_client 与 F_c、in_server，
   echoed 不变——模拟包在发生器→代理一段按注入同一存活率被台架吞掉），
   看 OLD 与 D 各自怎么动。此层是算术扰动、不冒充实测，文中单独标注。

## 预注册预测（跑分前写死，错了在正文公开认）

P1：A 层 q=0 四轮 D 全部 ≤ 0.03（段内无注入丢弃，只剩跳间缺口噪声）。
P2：A 层 CAND 在 q ≥ 0.20 各档触发率 4/4，q=0.10 档为临界档（D 在
    0.10 线两侧，不预言方向）；OLD 在隔离口径 q ≤ 0.40 触发 0 的旧结论复现。
P3：A 层 |D − q| 中位数 ≤ 0.02；两轮被台架顶过 0.75 的提前触发轮
    （q=0.20 第 2 轮、q=0.30 第 4 轮）其 D 仍落在各自 q ± 0.03 内
    ——即 CAND 不被台架缺口带偏。
P4：B 层 q=0.15 与 0.30 两档 CAND 触发 4/4、OLD 触发 0/4（部署口径
    允许台架偶发把 OLD 顶线，若出现逐轮用分解账归因、不改判定）。
P5：C 层 g 注入后 D 的变化 ≤ 0.005（构造性不变，只许数值噪声），
    OLD 的 L 随 g 单调升、g=0.3 时 q=0 轮次被顶过 0.75。
