# 台架缺口的负载定量实测 · 预注册（2026-11-03，跑分前冻结）

承接 2026-10-28 篇第 5 节未解问题：「本轮台架缺口随轮次漂移的规律
（与主机负载的定量关系）只做了观察，没有受控实验。」该篇实测：
发生器→代理缺口（1 − in_client/sent）在 28 轮里 0–29.8% 漂移；
2026-11-01/11-02 两批则逐轮为零。本轮受控改变 CPU 负载档位，
重复 q=0 基线轮（无额外丢弃、注入参数逐字不变），量缺口分布
随负载的漂移与上界，给注入带告警的误报余量一个可复核的成立条件。

## 受控设置（跑分前冻结）

- 链路与 2026-10-28 轮逐项相同：traffic_gen → fault_proxy →
  额外丢弃垫片（q=0，只计数不丢）→ echo_server，本机回环。
  注入参数逐字不变：loss 0.20 双向、delay 40 ms、jitter 30 ms、
  flap 0.6/2.5、代理种子 1234；流量 sustained 2000 pps × 5 s
  = 10,000 包、包长 256、收尾宽限 1.5 s。垫片种子基数 51000。
- 负载档位（本机 4 核）：以纯 CPU 忙循环进程（hog）数定档——
  L0=0 个、L1=2 个、L2=4 个（满核）、L3=6 个（1.5 倍超订）。
  hog 在每档首轮前启动、预热 3 s、该档全部轮次跑完后杀掉；
  hog 只烧 CPU、不占网络、不写盘（除启动行）。
- 每档 5 次重复，共 20 轮；档位顺序 L0→L1→L2→L3 不随机
  （如实标注：档位与墙钟顺序相关，靠每档前后的静默基线与
  逐轮负载读数对账，不许把顺序效应冒充负载效应——判定以
  逐轮实测 loadavg 与 hog 数共同为准）。
- 每轮记录：sent / in_client 及全链六跳计数（发生器→代理、
  代理→垫片、垫片→服务器、服务器→垫片、垫片→代理、
  代理→发生器）、exporter collect() 回读的 L 与五量、
  轮前 loadavg（1/5/15 分钟）与 MemAvailable、轮前后系统级
  UDP RcvbufErrors / InErrors 增量（/proc/net/snmp，系统级
  计数、含其他进程噪声，文中如实标注口径）。

## 量法（跑分前定义）

- 台架缺口 gap = 1 − in_client / sent（与前作同定义）。
- L = exporter 总丢包（部署口径）；L_iso = 以 in_client 为分母的
  隔离口径丢包；OLD 判定 L > 0.75。
- D = 1 − in_server / F_c，F_c = forwarded − echoed（2026-11-01
  篇重构式，逐轮验恒等式）；CAND 线沿用冻结的 D > 0.10。
- 抖动份额：代理日志去程/回程 drop_flap 占各自入数比例
  （与前作同口径，查注入基线是否随负载漂移）。
- 误报成立条件（解析层，非实测）：以本轮 L0 档 L_iso 均值为
  注入基线，解 1 − (1−g)(1−L_iso) = 0.75 得顶线所需缺口 g*，
  与各档实测 gap 分布（中位/最大）对照。

## 预注册预测（跑分前写死，错了在正文公开认）

P1 单调性：各档 gap 中位数随 hog 数非递减（允许 L0/L1 并列为零）。
P2 安静复现：L0 档 5 轮 gap 全部 ≤ 0.02（对齐 2026-11-01/11-02
    两批安静轮的 0–1.4% 量级）。
P3 负载效应：L3 档 gap 中位数比 L0 档至少高 0.01（1 个点）。
P4 误报余量：20 轮无一轮 gap ≥ g*（按 L_iso≈0.528 算约 0.47），
    且无一轮 OLD 触发（L ≤ 0.75）——即纯 CPU 负载（含超订）
    不足以单独把注入带告警顶线。
P5 机制归属：凡 gap 汇总 > 0.005 的档位，该档 RcvbufErrors
    增量合计 ≥ 该档 gap 包数合计的 50%（缺口主要落在接收
    缓冲溢出账上；系统级计数含噪声，达不到就如实报数不改口径）。
P6 分解免疫复现：20 轮 D 全部 ≤ 0.03（q=0、无段丢弃，负载
    多大都不许把 D 顶过噪声带——2026-11-01 篇免疫结论的
    受控负载复验）。

## 不许做的事

- 不许跑分后改档位、判定线（0.75 / 0.10）或 gap 定义再重报。
- 不许删轮：缺口异常、恒等式不成立的轮次留账单独说明。
- hog 是纯 CPU 负载发生器；内存/磁盘/网络负载不在本轮操纵
  范围，结论只许对 CPU 档位说，不许外推成「负载」全称。
